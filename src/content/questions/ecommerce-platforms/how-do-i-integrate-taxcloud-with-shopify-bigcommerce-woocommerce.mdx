TaxCloud has native apps and plugins for major ecommerce platforms, plus API access for custom setups. The integration routes checkout calculations through TaxCloud's SST-certified engine.

## Key takeaways

**Shopify:**
- Install the TaxCloud app from the Shopify App Store
- Connect using your TaxCloud API key from your TaxCloud account dashboard
- The app overrides Shopify's native tax calculation; Shopify Tax settings become inactive
- After connecting, enroll in AutoFile in your TaxCloud account for automated filing and remittance
- Ensure nexus states in TaxCloud match your registered states; TaxCloud calculates only for nexus states you've configured

**WooCommerce:**
- Install the TaxCloud WooCommerce plugin (available directly from TaxCloud or the WordPress plugin repository)
- Enter your TaxCloud API key and API ID in the plugin settings
- The plugin intercepts WooCommerce's checkout tax calculation and routes it to TaxCloud's engine
- Disable WooCommerce's built-in tax settings after connecting to avoid conflicts
- AutoFile enrollment is managed in your TaxCloud account, not in WooCommerce

**BigCommerce:**
- TaxCloud connects to BigCommerce via its API; a third-party connector or direct API integration is the standard approach
- BigCommerce's platform allows custom tax provider connections through its API; this may require developer assistance for initial setup
- Once connected, calculations and AutoFile enrollment work the same as other platforms

**After any integration:**
- Map your products to Product Tax Codes (PTCs) in TaxCloud; PTCs control state-specific taxability rules for your products
- Verify the integration with a test order in each nexus state before going live
- Confirm AutoFile enrollment state by state in your TaxCloud dashboard
